
# 🌌 Chronicle.md: Полное Руководство Мододела

Добро пожаловать в систему модификаций **Chronicle.md**! 
Плагин построен на архитектуре **Data-Driven**. Это значит, что вся логика вынесена в удобные текстовые файлы (JSON и CSS).

---

## 🛠️ СУПЕР-ИНСТРУМЕНТ: "Кузница Миров"
Вам **НЕ ОБЯЗАТЕЛЬНО** писать код руками!
Мы создали специальный визуальный редактор. Вы просто накликиваете предметы, цвета, события и эмоции, а он сам генерирует готовые `.json` и `.css` файлы.

**Как запустить Кузницу (2 способа):**
* **Способ 1:** Нажмите на иконку плагина (Мечи) в боковом меню Obsidian и выберите **«🛠️ Запустить Кузницу Миров»**. Браузер откроется автоматически!
* **Способ 2:** Найдите файл `🛠️ Кузница Миров.html` в левой панели Obsidian (в папке *Chronicle.md*), нажмите на него **правой кнопкой мыши** и выберите **«Открыть в приложении по умолчанию»** (Open in default app).


---
## 📥 Как установить созданный мод в игру?
Когда вы нажмете кнопку "Скачать" в Кузнице, браузер сохранит файлы на ваш компьютер. Чтобы плагин их увидел, их нужно положить в системную папку плагина.

**Путь к плагину:** `Ваше_Хранилище/.obsidian/plugins/chronicle-md/` 
*(Внимание: папка `.obsidian` обычно скрыта системой. Включите отображение скрытых файлов в вашей ОС, чтобы её увидеть).*

### 🧙‍♂️ Установка Компаньона:
1. Зайдите в папку `.../chronicle-md/companions/`
2. Создайте в ней новую папку. Назовите её **строго так же, как ID вашего компаньона** (например, `my_hero`).
3. Положите скачанный файл `companion_my_hero.json` в эту новую папку.
4. Создайте внутри папку с названием `sprites` и положите туда ваши картинки (например, `idle.png`). Без них плагин будет использовать эмодзи.

### 🌍 Установка Вселенной:
1. Зайдите в папку `.../chronicle-md/universes/`
2. Создайте в ней новую папку. Назовите её **строго так же, как ID вашей вселенной** (например, `my_universe`).
3. Положите туда скачанные файлы `universe_my_universe.json` и `universe_my_universe.css`.
4. (Необязательно) Создайте внутри папку `items_icon` и положите туда картинки для ваших предметов.

**Готово!** Теперь откройте меню плагина в Obsidian (иконка Мечей) и нажмите "Сменить Компаньона" или "Сменить Вселенную". Ваше творение появится в списке!

## 📂 Структура файлов
В корне папки плагина (`.obsidian/plugins/chronicle-md/`) вас интересуют две папки:
1. `companions/` — здесь живут ваши виртуальные напарники.
2. `universes/` — здесь создаются миры (сеттинги, предметы, интерфейс).

---

## 🎭 Часть 1: Создание Компаньона
Папка: `companions/id_компаньона/`. Файлы: `companion_<id>.json` и папка `sprites/` (для картинок).

### Система Настроения (Emotions)
```json
{
  "threshold": 70,
  "mood_name": "Просветление",
  "avatar_text": "🧙‍♂️✨",
  "icon_img": "happy.png",
  "phrases": {
    "greeting": "Магические потоки сегодня сильны!",
    "task_done": ["Превосходное плетение!", "Твоя воля изгибает реальность."],
    "task_undone": "Темные вихри... Зачем ты разорвал нить?",
    "level_up": "Достигнут уровень {level}.",
    "death": "Мы поглощены Пустотой."
  }
}
```
> [!info] Изящная Деградация
> Если плагин не найдет файл `happy.png` в папке `sprites`, он не выдаст ошибку, а красиво отрендерит эмодзи из `avatar_text`.

## 🌍 Часть 2: Создание Вселенной
Папка `universes/id_вселенной/`. Файлы: `universe_<id>.json`, `universe_<id>.css` и `items_icon/`.

### 1. Характеристики S.P.E.C.I.A.L.
Используйте теги с большой буквы (например, `#Sport` = **S**):
*   **S (Сила)**: +5 Макс. HP за очко.
*   **P (Восприятие)**: +2% к получаемому Золоту.
*   **E (Выносливость)**: Снижает урон за пропуски.
*   **C (Харизма)**: Скидки в Магазине.
*   **I (Интеллект)**: +2% Опыта.
*   **A (Ловкость)**: 2% шанс уклониться от урона.
*   **L (Удача)**: 1% шанс найти предмет.

### 2. Создание Предметов (Items)
Вы можете прописать `use_phrase` — фразу, которую скажет компаньон при использовании/надевании предмета!

**Расходники (Массив effects)**
```json
{
  "id": "energy_drink",
  "name": "Энергетик",
  "type": "consumable",
  "rarity": "rare",
  "icon_text": "🥫",
  "use_phrase": "Сердце бьется как бешеное!",
  "price": 50,
  "effects": [
    { "type": "gain_hp", "value": 50 },
    { "type": "lose_mood", "value": 20 }
  ]
}
```

**Экипировка (Бонусные статы)**
```json
{
  "id": "hat_star",
  "name": "Колпак Мага",
  "type": "equipment",
  "rarity": "epic",
  "equipSlot": "head",
  "price": 200,
  "use_phrase": "Надеюсь, мне идет.",
  "bonus_stats": { "I": 5, "C": -4 }
}
```

**Лутбоксы (Гача)**
```json
{
  "id": "mystery_chest",
  "name": "Сундук Удачи",
  "type": "lootbox",
  "rarity": "legendary",
  "price": 300,
  "lootbox_data": {
    "rolls": 2,
    "chances": { "common": 60, "rare": 30, "epic": 9, "legendary": 1 }
  }
}
```

### 3. Случайные события (Encounters)
Вы можете создавать любое количество кнопок (`choices`) и эффектов (`outcomes`).
```json
"encounters": [
  {
    "id": "wounded_merchant",
    "title": "Раненая Торговка",
    "description": "У вас просят помощи...",
    "icon": "🩸",
    "choices": [
      {
        "text": "Помочь (-10 Золота)",
        "outcomes": [
          { "type": "lose_coins", "value": 10 },
          { "type": "gain_mood", "value": 20 },
          { "type": "message", "text": "Она благодарит вас!" }
        ]
      }
    ]
  }
]
```

## 🎨 Часть 3: Стилизация (CSS)
Файл `universe_название.css` перекрашивает интерфейс.
```css
body {
    --background-primary: #1a1625;
    --background-secondary: #130f1c;
    --text-normal: #eaddb6;
    --interactive-accent: #f1c40f;
    --background-modifier-border: #4a3b52;
    --font-text: "Georgia", serif;
	
    /* Резервные цвета (если не заданы у компаньона) */
    --rpg-hp-color: #e74c3c;
    --rpg-xp-color: #9b59b6;
    --rpg-mood-color: #f1c40f;
}
```
**Создавайте, экспериментируйте и делитесь своими мирами!**
